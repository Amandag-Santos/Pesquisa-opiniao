# DS-Pesquisa_de_opiniao

## SOBRE O PROJETO

Este projeto em Python tem como objetivo coletar dados e fazer uma pesquisa sobre o atendimento de uma empresa.

O programa funciona de forma simples e interativa: o usuário digita nome  e idade, faz a avaliação sobre o atendimento, sendo ele exclente, bom ou ruim e o programa contabiliza a quantidade de respostas de cada avaliação.

**LINGUAGEM UTILIZADA**

 ![Python](https://img.shields.io/badge/python-3670A0?style=flat&logo=python&logoColor=ffdd54)
  
**COMO EXECUTAR?**

1 - Clone este repositório.

2 - Entre na pasta do projeto.

3 - Execute o arquivo Python.

4 - Informe o nome e idade quando solicitado pelo programa.

5 - Avalie o atendimento com uma nota entre 1, 2 e 3.
